# 鲨塘AI（shatangAI）：AI 营销视频生成平台

> 这是项目介绍页。源码属于公司，仓库为私有，这里不包含任何代码。

面向电商商家的 AI 视频生成平台：上传产品图或参考视频，生成可直接投放的营销短视频。线上运营中，有付费用户。

## 我做了什么

2026 年 4 月加入，至今是仓库提交最多的人：全仓约 3600 次提交，我约 2000 次。开发方式以 Claude Code 和 Codex 为主，由我拆需求、写设计文档、审查和验收 agent 的产出。

主要负责的部分：

- **视频生成链路**：多家视频模型的接入与线路切换、失败回退、分辨率升级通道
- **视频编辑与替换助手**：对话式的换人、换产品流程，分步自动汇报进度
- **脚本一键成片、爆款复刻**等玩法的前后端
- **积分与计价**：积分到期、退款回滚、按模型和档位计价
- **管理后台**：仪表盘指标、用户管理、转化漏斗、告警
- **市场与分销**：推广码、来源归因、商务跟进与监督

## 技术栈

| 层 | 技术 |
|---|---|
| 用户端 | React 19、Vite、Tailwind CSS、Zustand、React Router 7 |
| 后端 | Express 5、TypeScript、MySQL |
| 管理后台 | React 19、Recharts、JWT |
| 存储 | 阿里云 OSS |
| AI | 多家视频生成模型、通义千问视觉与图像模型 |
